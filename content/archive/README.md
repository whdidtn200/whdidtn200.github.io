# Archive

이 폴더는 MALT가 수집한 원본 소스를 보관하는 아카이브입니다.

## 권장 구조

- `sources/`
  수집한 전체 원본 소스 메모 JSON
- `unpublished/`
  아직 블로그에 발행되지 않은 논문 후보
- `published/`
  실제 블로그에 사용된 논문 소스
- `state/`
  현재 대기열과 파이프라인 상태 스냅샷
- `snapshots/`
  검색 결과 묶음, 주간 큐레이션 후보, 원문 발췌 메모

## 원칙

- 원본 링크와 수집 날짜를 남깁니다.
- 아직 발행하지 않은 자료도 먼저 archive에 넣습니다.
- 미발행 자료는 `unpublished/`에서 대기시킵니다.
- 발행에 사용한 자료는 `published/`로 이동시켜 재사용 여부를 구분합니다.
- 초안 생성은 archive에 쌓인 자료를 재사용하는 방식으로 진행합니다.
