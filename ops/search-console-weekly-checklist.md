# MALT Search Console Weekly Checklist

Last updated: 2026-06-19

## Goal

주 1회만 빠르게 확인해도, 검색 유입과 색인 상태가 악화되는 신호를 놓치지 않도록 만든 체크리스트입니다.

## Weekly rhythm

- 권장 빈도: 매주 1회
- 권장 요일: 금요일 또는 토요일
- 확인 대상: 대표 가이드, 실험실 최신 글, 최근 자동 발행 글

## 1. Performance

- `Search results > Performance`에서 최근 7일 클릭수와 노출수를 확인한다.
- 대표 가이드 3개가 최소한 노출되고 있는지 본다.
- 클릭이 생긴 쿼드가 어떤 의도인지 확인한다.
- CTR이 낮은 페이지는 제목과 설명이 너무 일반적인지 점검한다.

## 2. Indexing

- `Pages` 보고서에서 새로 늘어난 제외 사유가 있는지 본다.
- `Crawled - currently not indexed`가 급증했는지 확인한다.
- `Duplicate` 또는 `Alternate page with proper canonical` 비율이 갑자기 늘지 않았는지 본다.
- 최근 발행한 실험실 글과 가이드가 색인 후보로 보이는지 확인한다.

## 3. Priority pages

- 아래 페이지들은 매주 직접 확인한다.
- `/railway-predictive-maintenance-guide.html`
- `/bearing-fault-diagnosis-guide.html`
- `/wayside-condition-monitoring-guide.html`
- `/LAB.html`
- 최신 실험실 글 1개

## 4. Action rules

- 노출은 있는데 클릭이 없으면:
  제목, 첫 문단, 내부 링크 문구를 더 구체적으로 바꾼다.
- 색인 제외가 늘면:
  너무 짧은 페이지, 중복 허브, 설명이 약한 페이지를 우선 점검한다.
- 대표 가이드 노출이 약하면:
  홈, 가이드 허브, 관련 포스트에서 내부 링크를 한 번 더 강화한다.
- 새 글 노출이 약하면:
  발행량을 늘리기보다 기존 대표 페이지를 더 키운다.

## 5. Short log template

매주 아래 형식으로 짧게만 남기면 충분합니다.

```text
Date:
Clicks / Impressions:
Top page this week:
New indexing issue:
Pages to improve next:
```
